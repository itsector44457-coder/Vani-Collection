# Vani Collection · Jaipur Atelier 🌸

A luxury Indian ethnic wear e-commerce experience celebrating authentic craftsmanship, pure handwoven 100-count Mul Cotton, and traditional Bagru block prints.

## ✨ Key Features
- **Editorial Dual-Mode Hero**:
  - Live Atelier Video exploration background (60 FPS smooth playback)
  - Curated high-fashion Image Slideshow
  - Single luxury "Explore Collection" CTA
- **Mobile-First Experience**:
  - Featured Atelier 4-product 2x2 luxury showcase on mobile
  - Bottom sticky navigation with safe-area insets
  - Touch-optimized drawer menus & size selectors
- **Boutique E-Commerce Suite**:
  - Category story highlights & reels
  - Curated Bento collections (Mul Cotton, Festive Heirlooms, Co-ord Sets, Under ₹1,999)
  - Interactive Editorial Lookbook with shoppable hotspots
  - Slide-over Cart Drawer with real-time free shipping progress bar & coupon system
  - Lenis smooth momentum scrolling
- **Design Aesthetic**:
  - Royal Jaipur palette (Crimson, Deep Wine, Warm Cream, Antique Gold)
  - Serif typography (`Playfair Display` + `Plus Jakarta Sans`)
  - Glassmorphic luxury components & micro-interactions

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the application.

### Backend Setup (Optional API Server)
```bash
cd backend
npm install
node server.js
```

## 🛠️ Tech Stack
- **Framework**: Next.js 16 (App Router)
- **Styling**: Tailwind CSS v4 & Vanilla CSS
- **Animations**: Framer Motion
- **Smooth Scroll**: Lenis (`lenis/react`)
- **Icons**: Custom SVG & Lucide Icons
- **TypeScript**: Strict type checking
